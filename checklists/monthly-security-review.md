# Monthly Security Review

- [ ] Install pending Android, One UI, Google Play system, and application updates.
- [ ] Review security patch level.
- [ ] Confirm remote locate, lock, and erase access.
- [ ] Confirm recent encrypted backup success.
- [ ] Review installed applications and remove unused ones.
- [ ] Review high-risk permissions and special access.
- [ ] Review account sessions and connected devices.
- [ ] Confirm VPN/secure-access behavior on an untrusted test network.
- [ ] Confirm critical alerts reach the correct modes.
- [ ] Check unusual battery and data use.
- [ ] Verify NetWatch v2.0 opens in one action on the tablet.
- [ ] Review exceptions and assign remediation dates privately.

Quarterly, also test a non-sensitive restore, review app approvals, inspect authentication recovery, and rehearse lost-device actions.
