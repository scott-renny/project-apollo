# Galaxy S25 Build Checklist

## Baseline

- [ ] Record model, software version, ownership, and purchase details privately.
- [ ] Install all operating-system, security, and application updates.
- [ ] Set a unique strong PIN/password and enroll required biometrics.
- [ ] Configure automatic locking and private lock-screen notifications.
- [ ] Enable and test approved remote locate, lock, and erase services.
- [ ] Protect primary accounts with strong MFA and independent recovery.
- [ ] Enable encrypted backup and record the last successful test privately.

## Network and applications

- [ ] Disable automatic connection to unknown Wi-Fi.
- [ ] Configure and test the approved secure access route.
- [ ] Restrict USB data while locked.
- [ ] Install only applications approved in the inventory.
- [ ] Review all permissions and special access.
- [ ] Configure monitoring-only access for quick status checks.

## Experience

- [ ] Apply the approved Apollo wallpaper and lock screen.
- [ ] Confirm icon, widget, clock, and notification readability.
- [ ] Implement priority phone modes.
- [ ] Test critical alerts in Daily, Work, Study, Travel, and Sleep modes.
- [ ] Confirm every mode restores normal settings when it exits.

## Validation

- [ ] Complete a non-sensitive backup/restore test.
- [ ] Rehearse lost-device access from a separate trusted device.
- [ ] Run the portfolio sanitization checklist before publishing evidence.
