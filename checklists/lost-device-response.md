# Lost-Device Response

Use a separate trusted device. Preserve personal safety; do not attempt physical recovery from a dangerous location.

## Immediate actions

- [ ] Determine whether the device is misplaced, lost, or stolen.
- [ ] Use the approved device-finding service to locate, ring, and lock it.
- [ ] Display a safe return message without revealing private information.
- [ ] If theft is suspected, contact the carrier and suspend the SIM/eSIM as appropriate.
- [ ] Revoke active sessions for primary email, Google/Samsung accounts, password manager, VPN, Git hosting, and administrative services.
- [ ] Revoke device-specific certificates, SSH keys, tokens, and passkeys where applicable.
- [ ] Preserve a private timeline of actions.

## Erase decision

Remote erase when recovery is unlikely, the device contains sensitive material, lock integrity is uncertain, or policy requires it. Confirm the exact target before erasing. Understand that location tracking may stop after erase.

## After containment

- [ ] Change credentials that may have been exposed; do not rotate everything blindly if session revocation is sufficient.
- [ ] Notify relevant household, work, or infrastructure contacts through private channels.
- [ ] File carrier, police, insurance, or vendor reports if appropriate.
- [ ] Restore a replacement device from a verified backup.
- [ ] Issue new device-specific credentials.
- [ ] Review logs for suspicious access.
- [ ] Document lessons learned privately and publish only sanitized conclusions.
