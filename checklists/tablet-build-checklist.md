# Galaxy Tab S11 Build Checklist

## Baseline

- [ ] Record device and software details privately.
- [ ] Install all updates.
- [ ] Configure unique strong unlock and required biometrics.
- [ ] Hide sensitive lock-screen content.
- [ ] Enable and test remote locate, lock, and erase.
- [ ] Protect accounts with strong MFA and independent recovery.
- [ ] Configure encrypted backup.

## Portable operations console

- [ ] Configure the approved secure access route.
- [ ] Install only approved monitoring, documentation, and administration tools.
- [ ] Use separate monitoring and administrative accounts where possible.
- [ ] Put NetWatch v2.0 one action from the unlocked home screen.
- [ ] Build the operations dock.
- [ ] Test NetWatch in trusted-network and remote-access scenarios.
- [ ] Prepare NetWatch + notes, NetWatch + SSH, and NetWatch + runbook split-screen pairs.
- [ ] Validate DeX and keyboard/mouse behavior if used.

## Experience

- [ ] Apply landscape and portrait Apollo wallpaper/lock-screen variants.
- [ ] Confirm safe areas in both orientations.
- [ ] Implement priority tablet modes.
- [ ] Verify mode exit restores timeout, notification, orientation, VPN, and battery settings.

## Validation

- [ ] Test backup restoration with non-sensitive data.
- [ ] Rehearse loss response from a separate trusted device.
- [ ] Capture only sanitized demo evidence.
