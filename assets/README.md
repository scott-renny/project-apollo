# Asset Guidance

The repository intentionally ships without the referenced binary artwork because the original wallpaper and official emblem source files were not provided in this workspace.

## Add only approved source files

- `logos/`: official Hermes winged helmet, Hydra multi-headed serpent, and Apollo stylized A masters.
- `wallpapers/`: exports from the single shared master composition.
- `lockscreens/`: clock-safe exports from that same master.
- `screenshots/`: sanitized demonstrations only; keep raw captures outside Git.
- `diagrams/`: portfolio-safe architecture and workflow visuals.

Follow `docs/visual-identity-standard.md` for naming and `docs/portfolio-and-sanitization.md` before committing any image.
