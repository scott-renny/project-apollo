# Galaxy Tab S11 Modes

## Priority for v1

Personal, Network Operations, COC Analyst, Study, Documentation, Home Command Center, and Incident Response Console.

## Personal Tablet

Provides media, browsing, reading, communication, and family applications with normal battery and notification behavior. Operations tools remain on a dedicated page or dock.

## Network Operations

Makes NetWatch v2.0 the primary experience. Uses landscape orientation, verifies the approved secure route, extends timeout, silences entertainment, and prepares NetWatch with notes, SSH, or runbooks in split screen. See `docs/netwatch-quick-access.md`.

## COC Analyst

Surfaces Wazuh, NetWatch, Argus, logs, documentation, and input accessories. Supports DeX when appropriate. Minimizes messaging interruptions and uses only sanitized evidence capture.

## Incident Response Console

Pins NetWatch, approved administration, Wazuh, Argus, communications, notes, and runbooks. Requires secure connectivity, uses multi-window, reduces power-saving restrictions temporarily, and restores defaults on exit.

## Study and Certification

Pairs training content with notes, keyboard input, calendar, flashcards, and a study timer. Mutes entertainment and limits operational interruptions to high severity.

## Documentation

Surfaces Git hosting, browser, notes, cloud storage, Markdown editing, files, and annotation tools. Supports keyboard, mouse, and DeX; keeps personal applications out of the work surface.

## Home Command Center

Centers Athena, household schedules, Hestia, home controls, and a summarized NetWatch view. A docked shared-console configuration must avoid exposing administrative sessions or private notifications.

## Media

Optimizes playback, rotation, sound, and brightness; surfaces Hestia and media apps while permitting critical operational alerts only.

## Travel Console

Requires the approved secure route for internal access, hides sensitive notifications, surfaces travel documents and communication, limits discovery, and supports DeX as a temporary workstation.

## Presentation and Portfolio

Uses mock or sanitized dashboards, hides personal apps and notifications, increases readability, and exposes only portfolio-safe diagrams, repositories, and demo data.
