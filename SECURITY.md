# Security Policy

## Reporting a problem

Do not open a public issue containing credentials, access details, private addresses, screenshots of live dashboards, or other exploitable information. Use the repository owner's private reporting channel.

## Repository scope

This repository documents a security baseline; it is not a vault. It must never contain:

- passwords, passkeys, tokens, cookies, or session data;
- MFA seeds, recovery codes, or authenticator exports;
- VPN profiles, private keys, certificates, or SSH material;
- real internal URLs, IP addresses, hostnames, ports, or network diagrams;
- serial numbers, IMEIs, MAC addresses, phone numbers, or account identifiers;
- unredacted screenshots, notifications, calendars, or family information;
- device backups or diagnostic exports.

If sensitive data is committed, treat it as compromised: revoke or rotate it first, remove it from history, and document the incident privately.

## Supported documentation

Security corrections are accepted for the latest release. Device settings must be revalidated after major Android, One UI, application, or infrastructure changes.
