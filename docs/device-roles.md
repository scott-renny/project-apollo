# Device Roles

## Galaxy S25 — Mobile Command Device

Primary responsibilities:

- receive high-severity operational alerts;
- provide calls, messaging, calendar, and emergency communication;
- hold day-to-day authentication tools with secure recovery elsewhere;
- perform quick health checks and bounded response actions;
- capture notes and sanitized evidence;
- provide travel, navigation, and household quick controls.

The phone is not intended for prolonged dashboard analysis, bulk administration, or storage of the only recovery copy.

## Galaxy Tab S11 — Portable Operations Console

Primary responsibilities:

- present NetWatch v2.0 as the main portable network view;
- support dashboard triage, investigation, and documentation;
- provide approved SSH or browser-based administration;
- use landscape, split screen, keyboard, mouse, and DeX workflows;
- support study, certification, portfolio, and household-console modes.

The tablet should use a standard account for routine activity. Elevated access is used only when needed, with reauthentication and an approved secure network path.

## Shared boundaries

Both devices:

- use unique strong unlock credentials;
- hide sensitive notification content on the lock screen;
- receive automatic operating-system and application updates;
- use device encryption and verified remote-location/wipe services;
- connect to internal services only through an approved encrypted route;
- avoid storing secrets in notes, screenshots, downloads, or source control;
- keep recovery codes and break-glass material off-device.

## Decision rule

If a task takes less than a few minutes and is alert-driven, use the phone. If it requires comparison, logs, typing, multiple windows, or sustained attention, use the tablet.
