# Application Standard

Applications are approved by capability, source, data access, update history, and necessity—not popularity.

## Approval criteria

- Clear purpose aligned to a device role.
- Trusted publisher and verified installation source.
- Maintained security updates and supported Android version.
- Minimal required permissions and acceptable data collection.
- Export, backup, and account-recovery behavior understood.
- No duplicate capability without a documented reason.

## Required capability groups

| Capability | Phone | Tablet |
|---|---:|---:|
| Password manager and authentication | Required | Required, with limited recovery material |
| Approved VPN/secure access | Required | Required |
| NetWatch v2.0 access | Quick status | Primary experience |
| Secure browser | Required | Required |
| SSH/remote administration | Emergency only | Approved workflows |
| Notes/documentation | Capture | Authoring |
| Device finding and backup | Required | Required |
| Git hosting client/browser | Optional | Recommended |
| Household controls | Quick actions | Console layout |

## Review lifecycle

Review each application before installation, monthly for unusual battery/data use, quarterly for permissions, and whenever ownership, pricing, privacy policy, or support status changes.
